# ИГРА ЖИЗНЬ
Игра жизнь, написанная на C++, библиотека SFML. Изначально в ней установлены стандартные правила (B3/S23, для рождения клетки вокруг неё должно быть 3 живые клетки, для её сохранения вокруг должно быть 2 либо 3 клетки).

УПРАВЛЕНИЕ:
[LEFT CONTROL] - единого шага (нажать)
[SPACE] - для цикличного повторения шагов (зажать) 
[LEFT CLICK] - для установки клетки
[RIGHT CLICK] - для удаления клетки
